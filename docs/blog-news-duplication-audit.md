## 4. 样板重复（首段首句 / 末段末句）

- **逐字重复**：首句、末句做「前 60 字精确匹配」→ **0 组**。LLM 每次措辞不同，无硬编码模板句。
- **结尾 CTA 高度模板化**（去标点后取前 12 字聚合，≥2 次）：
  - 「如果你正在规划澳洲博士申…」 → **4 篇**（`e3a36834 / 35ee9302 / d97fbf12 / 9992522d`）
  - 「如果你希望系统梳理自己的…」 → 2 篇（`13685d92 / 1d909482`）
  - 「如果你正在寻找与自己研究…」 → 2 篇（`adc8988e / e844f279`）
- 样本（各篇末句）几乎都是「如果你正在/希望… Koala PhD（收录了澳洲各高校在研项目与导师…）」的软性引导。这是 System Prompt 里"Koala PhD 提及放在末尾"的固定套路，属**结构性样板**，非逐字重复。

## 6. 生成链路

### 6.1 入口

| 层 | 文件 | 说明 |
|---|---|---|
| 选题 | `app/api/blog/topics/route.ts`（GET） | 产出候选选题列表 |
| 单篇生成 | `app/api/blog/generate/route.ts`（POST） | 传入 `topic/category/style` → LLM 写文 → insert `blog_posts` |
| 批量生成 | `app/api/blog/batch-generate/route.ts`（POST，requireAdmin） | 循环对 topics 逐条调用 `/api/blog/generate` |
| 前端 | `app/dashboard/koala/ai-content/page.tsx`（单篇）、`app/dashboard/koala/ai-content/batch/page.tsx`（批量：`GET /api/blog/topics?count=8` → 勾选 → 逐条 `POST /api/blog/generate`） | 后台管理员手动触发 |

**无自动 cron**：`vercel.json` 的 crons 与 `app/api/cron/*` 均**不写 `blog_posts`**（`fetch-sydney-events` 只写活动数据，非博客）。新闻类文章全部由后台管理员手动批量生成。

### 6.2 选题怎么产生

`/api/blog/topics`：
1. **外部事件源（近 48h）**：用 Claude `web_search_20250305` 工具，随机取 4 条查询（`Australia PhD funding news`、`Australian university policy`、`international student Australia`、`OpenAI DeepMind AI research`、`cost of living students`、`tech industry hiring PhD`），只保留 48 小时内的新闻，喂给 LLM 产出 8 条选题（title/category/style/source/reason）。
2. **LLM 自由生成（兜底）**：若 web_search 无近况结果，走 `FALLBACK_PROMPT`——让 LLM **基于自身知识**围绕 6 大固定主题（教育政策 / 学术动态 / 国际时事 / 科技AI / 留学生活 / 职业产业）自由编选题。
   - **这是重复的根因之一**：查询词与 6 大主题是**硬编码固定列表**，每次批量都在同一小圈子里选题；兜底路径更是无外部信号、纯凭模型知识反复生成"AI 重塑科研 / 科研经费 / 生活成本 / 签证政策"这几个母题。

### 6.3 生成前是否查重

**否——三处均无任何查重**：
- `topics/route.ts`：产出选题时**不比对**已有文章标题/向量，历史选过的母题会被反复选中。
- `generate/route.ts`：`insert` 前只做 `topic` 非空校验、`max_tokens` 截断校验；**直接 `db.from('blog_posts').insert(row)`**，不查 title/category/embedding 是否已存在近似文章。
- `batch-generate/route.ts`：只透传，不去重。
- 对比：教授类 `generate-professor` 已在 2026-08-04 加了 `professor_id` 查重闸门；**新闻类没有任何等价机制**，且 `blog_posts` 无标题/内容维度的唯一约束或相似度校验。
